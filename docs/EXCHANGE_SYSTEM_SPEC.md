# Exchange System Spec

El modulo de equivalencias sera configurable por organizacion, profesional y cliente.

## Entidades

- Grupo y subgrupo.
- Nutriente principal.
- Cantidad objetivo.
- Alimentos incluidos y excluidos.
- Cantidad equivalente calculada.
- Ajuste manual con motivo.
- Medida casera.
- Tolerancia.
- Version.
- Fuente.
- Poblacion.
- Estado de publicacion.

No existe un sistema universal de equivalencias en Nutri-Oli. Las plantillas iniciales seran editables y no se presentaran como norma clinica unica.
