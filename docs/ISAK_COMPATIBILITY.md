# ISAK Compatibility

Nutri-Oli buscara compatibilidad operativa con practica antropometrica tipo ISAK, pero no esta certificado por ISAK y no reproduce manuales protegidos.

## Limites

- El profesional debe configurar protocolos conforme a su acreditacion y manual vigente.
- Los umbrales de discrepancia, repeticiones y reglas de medida son configurables y requieren validacion.
- Las ecuaciones deben registrar fuente, poblacion, version y limitaciones.

## Fase 1

Solo existen calculos basicos no diagnosticos para crear la base de tests.
