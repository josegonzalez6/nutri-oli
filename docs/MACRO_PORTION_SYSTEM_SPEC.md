# Macro Portion System Spec

Nombre interno: Planificacion por raciones de macronutrientes.

## Regla principal

El profesional define cada sistema:

- 1 racion de HC = X g de hidratos.
- 1 racion de proteina = X g de proteina.
- 1 racion de grasa = X g de grasa.

No se hardcodea una definicion universal.

## Alimentos mixtos

Un alimento puede aportar simultaneamente raciones de HC, proteina, grasa y fibra. El motor nutricional unico calcula macros reales y cobertura de datos, y el planificador usa esas cifras para alternativas y objetivos por comida.
