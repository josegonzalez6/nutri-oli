# Assumptions

- Idioma principal `es`; catalan preparado desde el inicio con `ca`.
- Zona horaria por defecto `Europe/Madrid`.
- Formato monetario EUR y locale `es-ES`.
- Registro libre de clientes desactivado por defecto.
- Los datos demo son ficticios y no representan pacientes reales.
- El acceso a GitHub existe a nivel de repositorio remoto, pero la autenticacion local de `gh` esta invalida en esta maquina.
- Las capturas mencionadas en la especificacion no estan presentes en el workspace.
