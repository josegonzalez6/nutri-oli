# User Manual - Client

- `/es/portal`: pantalla de encuadre del portal con contenido publicado de ejemplo.

## Pendiente

- autenticacion real del cliente;
- aceptacion de invitacion;
- consentimientos;
- plan publicado;
- citas propias;
- seguimiento habilitado por profesional;
- progreso;
- mensajes;
- documentos;
- cuenta, sesiones, exportacion y revocacion.

El cliente solo podra ver datos reales cuando Auth, RLS, portal persistente y validaciones esten completados.
