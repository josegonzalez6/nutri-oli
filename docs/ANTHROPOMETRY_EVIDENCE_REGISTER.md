## Reglas

- Las fuentes secundarias sirven para priorizar revision, no para activar formulas.
- Ninguna ecuacion predictiva avanzada queda habilitada en esta fase.
- Los indices simples habilitados son calculos reproducibles sin interpretacion automatica: IMC y cintura/talla.
